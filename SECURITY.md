# Security Policy

## Supported version

Security fixes target the latest version on `main`.

## Report a vulnerability

Please do not open a public issue. Email `security@closespan.com` with:

- The affected component and potential impact
- Steps to reproduce or a minimal proof of concept
- A suggested fix, if you have one

Remove secrets and real customer data before sending. We will acknowledge the
report and coordinate remediation and disclosure with you.
