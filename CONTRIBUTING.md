# Contributing

Thanks for helping improve CloseSpan.

1. Open an issue before starting a substantial behavior change.
2. Create a focused branch and keep the change small.
3. Run the relevant checks:

   ```bash
   npm run lint
   npm test
   npm run typecheck
   ```

4. Open a pull request with a short summary, test evidence, and screenshots for
   visible UI changes.

Never commit secrets or customer data. By submitting a contribution, you agree
that it is licensed under the [Apache License 2.0](LICENSE).
