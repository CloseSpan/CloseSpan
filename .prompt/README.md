# CloseSpan implementation prompts

Files in `tickets/` are immutable, approval-bound implementation contracts generated by CloseSpan.

- Do not edit an approved prompt on an agent work branch.
- Every acceptance criterion must map to at least one test scenario.
- Automated checks prove implementation-level acceptance only; release verification remains separate.
- Agents may change only the permitted paths and must never modify `.github/workflows/**`.
- Agents stop after creating a reviewable branch and draft pull request. They never merge or deploy.

Use `template.prompt.md` when reviewing the fields that CloseSpan will generate. Ticket files are created only on approved work branches.
